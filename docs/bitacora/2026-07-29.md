## Decisiones tomadas
- **Envíos por `revision_id`**: Evita ambigüedades cuando existen múltiples borradores para la misma gestión.
- **Decisión explícita**: La revisión solo se finaliza cuando el Vicerrector presiona un botón de decisión explícito.
- **Plan de elevación**: Se documentó modelo objetivo aprobado para normalización académica, roles, propuestas versionadas, revisión, importación, notificaciones y calidad.
- **Testing aislado**: Las pruebas quedan apuntando por defecto a `designaciones_uatf_testing`; usuario y contrasena se cargan desde `.env.testing` local para no volver a exponer secretos.
- **Migración gradual de grupos**: La nueva FK de malla es nullable para conservar todos los grupos existentes mientras se inventarían y migran sus asociaciones históricas.
- **Gestión actual explícita**: El nuevo indicador inicia en `false`; no se infiere desde el año del servidor ni desde el nombre de una gestión.
