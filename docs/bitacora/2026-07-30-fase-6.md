## Objetivo del dia

Eliminar las rutas y pantallas duplicadas para que cada rol tenga un unico camino de trabajo con designaciones.

## Que se hizo

- Se consolido el acceso del Director en `/designaciones` y la bandeja de Vicerrectorado en `/revisiones/pendientes`.
- Se retiraron los controladores, formularios, politicas, servicios y pruebas del CRUD historico, revision historica, importacion masiva y dashboard que ya no representaban el proceso vigente.
- Se agregaron restricciones numericas a las rutas de recursos; por ello `/designaciones/create` deja de resolverse como una designacion y responde como ruta inexistente.
- Se conservaron las tablas historicas para no perder informacion ni impedir la importacion de datos anteriores.
- Las notificaciones guardadas con URLs antiguas se traducen a las URLs actuales al abrirse.
- Se actualizaron README, contexto de agentes y modelo de datos para describir el flujo real.

## Decisiones tomadas

- El nombre visible para Directores es "Designaciones" y para Vicerrectorado "Bandeja de Revisiones". Los nombres tecnicos de modelos versionados permanecen internos.
- No se eliminan migraciones ni tablas aplicadas: retirar datos historicos seria un riesgo innecesario y no aporta al flujo nuevo.
