# Archivo documental

Este directorio conserva documentos históricos, planes de fases, bocetos,
bitácoras y mapas que ya no son la entrada principal del proyecto. No se
eliminan: se mueven para conservar su contenido y su historial Git.

La documentación vigente está en:

- `README.md`
- `docs/ARCHITECTURE.md`
- `docs/BUSINESS_RULES.md`
- `docs/OPERATIONS.md`
- `docs/TESTING.md`
- `docs/INTEGRATION_JACHASUN.md`

Los archivos de `docs/testing/` que no son `STATUS.md`, `TEST_MATRIX.md` o
`BUG_REPORTS/` son históricos y se conservan en `archive/testing/`.
