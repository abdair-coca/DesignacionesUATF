# Bitacora - 2026-07-30

## Objetivo del dia

Elevar el sistema de Designaciones desde la normalizacion academica hasta un flujo trazable de borrador, revision y aprobacion, y dejar una unica experiencia coherente por rol.

## Que se hizo

- Fase 0: se preparo la base de pruebas PostgreSQL, los controles de calidad y la auditoria de normalizacion academica.
- Fase 1: se normalizaron materias, malla curricular y grupos para que un mismo codigo de grupo pueda existir en carreras distintas sin mezclar designaciones.
- Fase 2: se separaron los roles `director_carrera` y `vicerrectorado`, con permisos y alcance por carrera aplicados en servidor.
- Fase 3: se crearon borradores por carrera, gestion y periodo; cada envio genera una version numerada con snapshots inmutables.
- Fase 4: se implemento la bandeja de revision, decisiones completas o por fila, observaciones, reenvio y bloqueo de filas aprobadas.
- Fase 5: se agregaron importacion historica segura, previsualizacion, eventos de auditoria y notificaciones internas.
- Fase 6: se eliminaron rutas, controladores y logica duplicada del sistema heredado. Director usa `/designaciones` y Vicerrectorado `/revisiones/pendientes`.
- Se recuperaron las presentaciones anteriores de la lista de Designaciones y la bandeja de Revisiones, conectadas solamente al flujo nuevo.
- Se recupero la pantalla detallada de asignacion por docente para cada propuesta. Conserva la edicion, importacion, envio y retiro sobre el borrador versionado, y muestra el historial real de revisiones sin reactivar rutas ni escrituras legadas.
- Se genero un grafo de conocimiento con Graphify para documentar las clases y relaciones del repositorio.
- Se ejecuto la suite final con 53 pruebas y 236 aserciones; Pint finalizo correctamente.

## Decisiones tomadas

- Se preservan los datos y tablas historicas como fuente de importacion, pero no sus rutas ni acciones de edicion directa.
- La interfaz anterior se conserva cuando aporta valor, sin reactivar logica o endpoints heredados.
- El flujo no se considerara completamente aceptado hasta ejecutar una validacion integral con usuarios y datos representativos.
- El grafo se conserva en version control sin su cache para que sea reproducible y no agregue archivos regenerables.
